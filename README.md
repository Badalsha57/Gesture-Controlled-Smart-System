# Gesture Controlled Smart System

A real-time gesture-controlled smart system built using **Python**, **OpenCV**, and **MediaPipe**.  
Control presentations, media, and dashboards using simple hand gestures without touching a keyboard or mouse. 🖐️💻

---

## Features

### 1. Menu Mode
- Navigate between different modes:
  - Presentation
  - Media
  - Dashboard
  - Exit
- Select modes by pinching thumb + index finger on a menu option.

### 2. Presentation Mode
- **Next Slide:** Pinch thumb + index finger.
- **Previous Slide:** Move thumb away from index.
- **Back to Menu:** Fist gesture (index + middle fingers closed).

### 3. Media Mode
- **Play/Pause:** Pinch thumb + index finger.
- **Volume Control:** Move hand up/down to increase/decrease volume.
- **Fullscreen Toggle:** Pinch index + middle fingers.
- **Back to Menu:** Fist gesture (index + middle fingers closed).

### 4. Dashboard Mode
- **Volume Control:** Move hand up/down.
- **Back to Menu:** Fist gesture (index + middle fingers closed).
